Estación 2: Especificación de Requerimientos y Alcance

Documentación semántica y backlog de tareas para la arquitectura del portafolio estático.

1. Estructura de Secciones Fijas

Sección Objetivo UX / Arquitectura Componentes Semánticos (HTML5)
Inicio Captar atención inmediata con propuesta de valor y rol principal. <header>, <h1>, titular dinámico, botones CTA.
Sobre mí Contextualizar trayectoria, filosofía de desarrollo y perfil profesional. <section>, <p>, enlace de descarga de CV, bio corta.
Proyectos Demostrar capacidad técnica funcional mediante trabajos previos. Grid de <article>, <img>, tags de tech y enlaces externos.
Habilidades Resumir visualmente el stack tecnológico clave sin saturar. <ul>, <li>, badges/chips categorizados.
Contacto Facilitar vías directas de comunicación con reclutadores o clientes. <form>, <label>, <input>, enlaces sociales semánticos.

2. Tablero de Historias de Usuario (Sprint Backlog)

US-01 | Alta

Galería Interactiva de Proyectos

Como reclutador técnico, quiero explorar un catálogo visual con los proyectos destacados, para examinar el código fuente y las demos en vivo.

Criterio de aceptación: Layout tipo grid con mínimo 3 proyectos, enlaces funcionales a GitHub y despliegue activo.
US-02 | Alta

Navegación Fija y Fluida

Como visitante, quiero utilizar una barra de navegación accesible desde cualquier punto de la página, para moverme rápido entre secciones.

Criterio de aceptación: Menú con position: sticky o fixed, enlaces internos vinculados por IDs únicos y desplazamiento suave.
US-03 | Media

Desglose Categorizado de Stack

Como líder de ingeniería, quiero visualizar las tecnologías que domina el desarrollador por grupos (HTML, CSS, JS, Tools), para validar si calza con el equipo.

Criterio de aceptación: Lista ordenada por bloques temáticos con iconos o etiquetas legibles.
US-04 | Alta

Formulario de Contacto Directo

Como cliente potencial, quiero rellenar un formulario con mi correo y mensaje, para solicitar una entrevista o cotización formal.

Criterio de aceptación: Campos obligatorios (nombre, email, mensaje) validados mediante atributos nativos de HTML5.
US-05 | Media

Descarga Directa de Currículum

Como reclutador con tiempo limitado, quiero descargar la versión actualizada en PDF del CV mediante un botón claro, para archivarlo en el sistema ATS.

Criterio de aceptación: Enlace <a> con el atributo download hacia el documento PDF local.
